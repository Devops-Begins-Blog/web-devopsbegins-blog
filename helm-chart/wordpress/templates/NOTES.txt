ACCESSING WORDPRESS
--------------------------------------------------------------------------------

{{- if .Values.ingress.enabled }}

WordPress is accessible via Ingress:

{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}

{{- else if contains "NodePort" .Values.service.type }}

Get the WordPress URL by running:

  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "wordpress.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo "WordPress URL: http://$NODE_IP:$NODE_PORT"

{{- else if contains "LoadBalancer" .Values.service.type }}

Get the WordPress URL by running:

  NOTE: It may take a few minutes for the LoadBalancer IP to be available.

  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "wordpress.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo "WordPress URL: http://$SERVICE_IP:{{ .Values.service.port }}"

{{- else if contains "ClusterIP" .Values.service.type }}

Get the WordPress URL by running:

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "wordpress.fullname" . }} 8080:{{ .Values.service.port }}
  echo "WordPress URL: http://127.0.0.1:8080"

{{- end }}

TROUBLESHOOTING
--------------------------------------------------------------------------------

  kubectl logs --namespace {{ .Release.Namespace }} -l "{{ include "wordpress.selectorLabels" . | replace ": " "=" | replace "\n" "," }}" -f

Test health endpoint:

  kubectl exec --namespace {{ .Release.Namespace }} deploy/{{ include "wordpress.fullname" . }} -- curl -s localhost/health.php | jq
